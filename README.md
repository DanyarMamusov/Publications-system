# Publications-system
-----------------------------------------------------ИС учета научных публикаций---------------------------------------------------
Цели ИС:
Автоматизация учета научных публикаций сотрудников организации, обеспечение централизованного хранения сведений о публикациях, авторах и источниках, а также упрощение процесса проверки публикаций и формирования отчетности.

Папка diagrams: Содержит диаграммы UML, визуализирующие информационную систему

Папка database: Содержит файлы базы данных

Папка models: Содержит модели для работы с таблицами базы данных

Папка ui: Содержит файлы интерфейса для работы с программой

Файл main.py - Главный файл программы
